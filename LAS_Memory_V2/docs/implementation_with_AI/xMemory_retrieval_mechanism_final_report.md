# xMemory 하이브리드 RAG 기억 상기(Retrieval) 메커니즘 보고서

**작성일**: 2026-06-01  
**대상 시스템**: L.A.S. `xMemory` (LAS_Memory_V2)  
**주제**: 투 트랙(Two-Track) 검색 기반의 3단계 기억 상기 구조 분석

---

## 1. 개요 (Overview)
본 보고서는 L.A.S.가 사용자의 질문을 입력받았을 때, 방대한 벡터 데이터베이스(ChromaDB) 내부에서 필요한 기억(사실, 에피소드)을 어떠한 구조적 흐름을 통해 인출해 내는지(Retrieval)에 대한 핵심 메커니즘을 정의합니다. 특히 **상위 테마 기반의 정밀 검색**과 **미분류 팩트 포용**이 결합된 하이브리드 구조에 집중합니다.

---

## 2. 3단계 기억 상기 메커니즘

### Step 1: 큰 그림 파악 (Top-Down Theme Selection)
가장 먼저 사용자의 질문(Query)을 벡터로 임베딩한 후, 시스템에 하드코딩된 **10개의 최상위 테마(`level_3_themes`)**와 의미 유사도(Cosine Similarity)를 비교합니다.
- **테마 특정 (최대 3개)**: 질문과 가장 관련성이 높은 테마를 **최대 3개(Top-3)**까지 찾습니다. (단, 유사도가 `0.3` 미만인 테마는 제외됩니다.)
- **자아 유지 (상시 로드 1개)**: 사용자의 신상이나 핵심 정체성이 담긴 `T_10` 테마는 계산 결과와 무관하게 **항상 검색 필터에 강제 포함**시켜 L.A.S.가 주인을 잊는 현상을 방지합니다.
- **결과**: Step 1을 거치면 검색 대상이 될 테마 그룹은 **'매칭된 테마(최대 3개) + T_10'**으로 좁혀집니다.

### Step 2: 투 트랙(Two-Track) 하이브리드 사실 검색 ⭐️
가장 핵심적인 검색 단계로, 특정 테마에 종속된 기억과 일상적인 잡담(미분류 기억)을 동시에 건져 올립니다.

> [!IMPORTANT]
> **투 트랙(Two-Track) 그물망 투척**
> 1. **테마 그물망 (`$in: ['T_04', 'T_10']`)**: Step 1에서 선택된 특정 테마에 명확히 속한 팩트들만 정밀 타격하여 건져 올립니다. (노이즈 없는 고품질 맥락)
> 2. **미분류 그물망 (`$in: [""]`)**: 10대 테마에 속하지 못한 파편화된 일상 대화 기록(미분류 팩트)의 바다에도 그물을 던집니다.

위 두 그물망에서 올라온 모든 팩트(`level_2_facts`)들을 한곳에 모은 뒤, 오직 **질문과의 '의미적 유사도'**만을 기준으로 정렬하여 가장 적합한 **상위 10개(Top-10)**의 기억 조각을 최종 선발합니다. (`config.fact_top_k = 10`)
- **효과**: 관련 없는 테마(예: 요리 질문에 마인크래프트 테마)의 간섭은 완벽히 차단하면서도, 분류되지 않은 소소한 과거의 대화 내용들은 절대 유실되지 않고 RAG 시스템에 공급됩니다.

### Step 3: 원본 맥락 추적 (Episode Deep Search)
Step 2에서 인출된 단편적인 '팩트 조각'만으로는 사용자 질문의 앞뒤 맥락을 파악하기 힘들 때가 있습니다.
- 이때 L.A.S.는 팩트 메타데이터에 기록된 **`source_episode_id` (예: `E_811`)**를 활용하여 시스템 내장 도구(`deep_search`)를 호출합니다.
- SQLite(`level_0_raw`)에 저장된 과거 20턴 분량의 원본 대화 전체를 그대로 인출하여 프롬프트에 주입함으로써, 단순한 키워드 매칭을 넘어선 **'맥락 기반의 깊은 이해'**를 가능하게 합니다.

---

## 3. 결론
현재 적용된 xMemory의 구조는 **"분류된 뼈대 지식(테마)의 정밀함"**과 **"파편화된 무의식(미분류 팩트)의 유연함"**을 동시에 취하는 이상적인 형태입니다. 
- 헛소리(환각)는 엄격한 테마 필터링으로 차단하고,
- 기억의 유실(사각지대)은 빈 문자열(`""`) 하이브리드 검색으로 방지하는 **결함 없는(Zero-blind-spot) 기억 체계**가 완성되었습니다.
